## Estructura del repositorio

- `src/mochila.py`: Problema de la mochila 0/1 (recursión ingenua, memoización, tabulación y reconstrucción).
- `src/cambio.py`: Problema del cambio de monedas mínimo (recursión ingenua, memoización, tabulación y reconstrucción).
- `src/lcsq.py`: Subsecuencia común más larga (recursión ingenua, memoización, tabulación y reconstrucción).
- `src/lcs_substring.py`: Subcadena común más larga contigua (recursión ingenua, memoización, tabulación y reconstrucción).
- `tests/benchmark_y_casos.py`: Casos de prueba, validación de resultados, conteo de llamadas y medición de tiempos.

## Ejecución

Desde la raíz del proyecto, ejecuta:

```bash
python tests/benchmark_y_casos.py
```
